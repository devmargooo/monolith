## О проекте

Сервис предоставляет механизм аутентификации администратора, управление токенами доступа и поддержку защищённых соединений.

Стек:

- **Nx** – монорепозиторий для управления проектом
- **NestJS** – бэкенд на Node.js

Основные возможности:  
✅ Аутентификация администратора по логину и паролю
✅ Шифрование данных
✅ Управление сессиями

## Установка

```bash
   git clone git@github.com:devmargooo/monolith.git
   cd monolith
   npm i
```

## Запуск

```bash
   npx nx serve authservice
```

## Тестирование

```bash
   npx nx test authservice
```
